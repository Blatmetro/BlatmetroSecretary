# Blatmetro Secretary — Local AI

Telegram-бот, который передаёт сообщения локальной языковой модели через OpenAI-совместимый HTTP API `llama.cpp`. DeepSeek API-ключ не требуется: модель и `llama-server` работают на твоём компьютере.

## Важно

- Нужен токен Telegram-бота от `@BotFather`. Это отдельный токен Telegram, не ключ DeepSeek.
- Компьютер должен быть включён и подключён к интернету, пока бот отвечает.
- Модель запускается локально; Telegram Bot API всё равно использует интернет.
- Не публикуй `.env`, токен бота или `data/memory.json`.
- Acer с 4 ГБ RAM очень ограничен. Начинай с короткого контекста и маленькой GGUF-модели. Если памяти не хватает, бот может не получить ответ.

## 1. Подготовка

Установи Python 3.10+ и скачай совместимую GGUF-модель. Для первого теста подойдёт квантованная DeepSeek-R1-Distill-Qwen-1.5B, но на 4 ГБ RAM она может работать медленно или не поместиться вместе с Windows.

Скачай `llama.cpp` для Windows или собери его отдельно. Нужен исполняемый файл `llama-server.exe`.

## 2. Запусти модель

Пример команды (путь к GGUF замени на свой):

```powershell
llama-server.exe -m "C:\AI\DeepSeek-Qwen-1.5B-Q4_0.gguf" --host 127.0.0.1 --port 9931 -c 512 -t 2
```

Если памяти мало, закрой лишние программы. Не увеличивай контекст без необходимости.

Проверь в браузере `http://127.0.0.1:9931/`. Сервер должен быть запущен, пока работает бот.

## 3. Настрой Telegram-бота

1. Создай или выбери бота через `@BotFather`.
2. Получи токен Telegram.
3. Скопируй `.env.example` в файл `.env`.
4. Вставь токен в `TELEGRAM_BOT_TOKEN=`. Не отправляй его никому.
5. Установи зависимости и запусти `run_bot.bat`.

Бот использует long polling, поэтому отдельный публичный IP и открытие входящего порта на роутере не нужны.

## 4. Порядок запуска

1. Запусти `llama-server.exe` и дождись готовности сервера.
2. Запусти `run_bot.bat`.
3. Открой Telegram и напиши своему боту `/start`.

## Команды

- `/start` — приветствие
- `/help` — помощь
- `/reset` — очистить историю диалога этого пользователя

## Память и приватность

История хранится в `data/memory.json` на компьютере. Команда `/reset` удаляет историю только для Telegram-пользователя, который её вызвал. Не делай этот файл публичным и регулярно создавай резервную копию, если история важна.

## Ограничение первой версии

Это минимальный прототип: он отвечает на текстовые сообщения в личном чате, хранит короткую историю отдельно для каждого Telegram user ID и обращается к локальному серверу. Он пока не отправляет сообщения от имени твоего личного Telegram-аккаунта и не отвечает автоматически в твоих личных переписках.
